Notification 通知 ​

悬浮出现在页面角落，显示全局的通知提醒消息。

基础用法 ​

::: preview demo-preview=../demo/notification/Basic.vue :::

不同类型的通知 ​

提供了四种不同类型的提醒框：success、warning、info 和 error (danger 效果和 error 相同)。

::: preview demo-preview=../demo/notification/Type.vue :::

隐藏关闭按钮 ​

可以通过设置 closable 属性来隐藏关闭按钮。

::: preview demo-preview=../demo/notification/Closeable.vue :::

全局方法 ​

通过全局方法 $notify 调用，可以弹出通知。

单独引用 ​

typescript
import { KiyoNotification } from "kiyo-element";
